# TRT_HW
# STM32 Modular Audio Platform

Plataforma de hardware abierta en arquitectura Tarjeta Base y Hijas (Carrier & Daughterboard) para audio digital, DSP y control.

## Especificaciones
* MCU: STM32G474RET6 (Cortex-M4 @ 170MHz)
* Aceleradores: FMAC y CORDIC
* Bus B2B: I2S, I2C, SPI, ADC, GPIO
* Alimentación: USB-C / 9V DC
* ECAD: KiCad
